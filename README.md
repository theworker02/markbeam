# markbeam

Mark identifiers and beam tokens for idempotent workflows.

**Site:** https://theworker02.github.io/markbeam/

## Install / run

```bash
git clone https://github.com/theworker02/markbeam.git
cd markbeam
node src/cli.js
node --test
```
